## Test Approach

### What will be tested?
- ShoppersStack Login
- ShoppersStack Registration
- Valid and invalid inputs
- Field validations
- Error messages

### What types of testing are performed?
- Functional Testing
- Positive Testing
- Negative Testing
- Validation Testing

## How to Run Tests

- Open the required test case Excel file.
- Prepare the required test data.
- Execute the test steps.
- Compare the Actual Result with the Expected Result.
- Mark the test case as Pass or Fail.

## Test Data Setup

### Where is test data stored?
Test data is stored in the `test-data` folder.

### How should test data be prepared?
- Use valid data for positive test cases.
- Use invalid data for negative test cases.
- Use unique data for registration test cases.

## Bug Reporting

### How to report bugs?
- Reproduce the issue.
- Record the issue in the Bug Report Template.
- Add clear steps to reproduce the issue.
- Add screenshots or evidence when required.

### What information should be included in a bug report?
- Bug ID
- Bug Title
- Module
- Environment
- Steps to Reproduce
- Test Data
- Expected Result
- Actual Result
- Severity
- Priority
- Status
- Screenshot
