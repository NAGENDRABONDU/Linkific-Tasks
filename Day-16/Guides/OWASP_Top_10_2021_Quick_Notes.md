# OWASP Top 10 (2021) – Quick Notes

1. **A01 Broken Access Control:** Users access data or actions beyond their permissions.
2. **A02 Cryptographic Failures:** Sensitive data is not properly protected.
3. **A03 Injection:** Untrusted input is interpreted as commands or queries.
4. **A04 Insecure Design:** Security controls are missing from design.
5. **A05 Security Misconfiguration:** Unsafe defaults, settings, or verbose errors.
6. **A06 Vulnerable and Outdated Components:** Dependencies contain known vulnerabilities.
7. **A07 Identification and Authentication Failures:** Weak identity or session controls.
8. **A08 Software and Data Integrity Failures:** Software or data is not properly verified.
9. **A09 Security Logging and Monitoring Failures:** Security events are not adequately logged or monitored.
10. **A10 SSRF:** A server is tricked into making requests to unintended destinations.

Functional testing checks whether features work. Security testing checks whether data and features are protected against misuse.

Common types: vulnerability assessment, penetration testing, authentication testing, authorization testing, session testing, and configuration testing.

Tester responsibilities: stay within written scope, use test accounts, protect evidence, report impact and reproduction steps, and avoid destructive tests.
