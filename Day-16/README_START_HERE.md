# Day 16 – Security Testing Practical Pack

Included:
- 35 security test cases in `Test_Cases/Security_Test_Cases.csv`
- OWASP Top 10 (2021) quick notes
- OWASP ZAP beginner lab guide
- Security testing checklist

Recommended order:
1. Read the OWASP Top 10 notes.
2. Review and execute relevant test cases against a local or explicitly authorized application.
3. Complete the checklist.
4. Practise ZAP passive scanning on a local lab.
5. Save redacted screenshots and findings in `Evidence/`.

Safety: Only test systems you own or have explicit written permission to assess. Use a local intentionally vulnerable training app for active scanning. Do not run SQLMap, active scans, brute-force attempts, or intrusive tests against public services without written authorization.
