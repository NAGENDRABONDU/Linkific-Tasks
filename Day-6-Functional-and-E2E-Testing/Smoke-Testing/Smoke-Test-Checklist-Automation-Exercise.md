# Day 6 – Smoke Testing

## Project Details
- **Project Name:** Automation Exercise
- **Module Name:** Smoke Testing
- **Application URL:** https://automationexercise.com/

## Objective
Verify that the main website functions load and are available for further testing.

## Smoke Test Checklist

| Test Case ID | Test Scenario | Expected Result | Status |
|---|---|---|---|
| SM-001 | Open Automation Exercise home page | Home page loads successfully. | Not Executed |
| SM-002 | Verify main navigation | Main navigation links are visible and usable. | Not Executed |
| SM-003 | Open Signup / Login page | Signup / Login page opens and displays relevant fields. | Not Executed |
| SM-004 | Login with valid test credentials | User logs in successfully with a registered test account. | Not Executed |
| SM-005 | Login with invalid credentials | Login is rejected and an appropriate error message is displayed. | Not Executed |
| SM-006 | Open signup form | Signup form opens and required fields are available. | Not Executed |
| SM-007 | Open Products page | Products page loads and products are displayed. | Not Executed |
| SM-008 | Open product details | Selected product details are displayed. | Not Executed |
| SM-009 | Open Cart page | Cart page opens and displays items or an empty-cart state. | Not Executed |
| SM-010 | Verify logout | User can log out and the session ends. | Not Executed |

## Execution Notes
1. Open https://automationexercise.com/ in a browser.
2. Execute each test and record the actual result.
3. Update status to Pass, Fail, Blocked, or N/A only after execution.
4. Use only test accounts and safe test data.
5. Do not mark a test Pass without executing it.

## Status Definitions
- **Not Executed:** Test has not been run yet.
- **Pass:** Actual result matches the expected result.
- **Fail:** Actual result differs from the expected result.
- **Blocked:** Testing cannot continue due to an issue.
- **N/A:** The test does not apply.
