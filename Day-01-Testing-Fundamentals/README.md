## 5. Understand Testing Types

### Functional Testing

Testing whether the software functions according to requirements.

Examples:

- Smoke Testing
- Sanity Testing
- Regression Testing
- Retesting

### Non-Functional Testing

Testing quality attributes of the software.

Examples:

- Performance Testing
- Security Testing
- Usability Testing

### Maintenance Testing

Testing performed after changes or during maintenance.

Examples:

- Regression Testing
- Confirmation/Retesting

### Change-Related Testing

Testing performed after changes are made to the software.

Examples:

- Retesting
- Regression Testing

---

## 6. Learn Testing Levels

### Unit Testing

Testing individual components or units.

### Integration Testing

Testing interactions between combined components.

### System Testing

Testing the complete integrated application.

### Acceptance Testing

Testing whether the software meets business/user requirements
and is acceptable for release.

Basic flow:

Unit Testing
      ↓
Integration Testing
      ↓
System Testing
      ↓
Acceptance Testing

---

## 7. Learn the 7 Principles of Testing

Understand the following principles:

1. Testing shows the presence of defects
2. Exhaustive testing is impossible
3. Early testing
4. Defect clustering
5. Pesticide paradox
6. Testing is context dependent
7. Absence-of-errors fallacy

For each principle, understand:

- Definition
- Meaning
- Real-world example
- Testing example
