# SDLC & STLC

## 1. SDLC — Software Development Life Cycle

### Definition

SDLC is a step-by-step process used to develop, test, release, and maintain software.

### SDLC Phases

Requirement
↓
Planning
↓
Design
↓
Development
↓
Testing
↓
Deployment
↓
Maintenance

### Example

For a food delivery application:

- Requirement → Decide what the application should do
- Planning → Decide resources, time, cost, and team
- Design → Design the application
- Development → Developers write the code
- Testing → Testers test the application
- Deployment → Release the application
- Maintenance → Fix issues and improve the application

---

## 2. STLC — Software Testing Life Cycle

### Definition

STLC is a systematic process followed by the testing team to plan, prepare, execute, and complete software testing.

### STLC Phases

Requirement Analysis
↓
Test Planning
↓
Test Case Development
↓
Test Environment Setup
↓
Test Execution
↓
Test Closure

### Example

For a login feature:

- Requirement Analysis → Understand login requirements
- Test Planning → Decide testing approach and resources
- Test Case Development → Create login test cases
- Test Environment Setup → Prepare application, browser, test data
- Test Execution → Execute test cases
- Test Closure → Prepare test summary and close testing

---

## 3. SDLC vs STLC

| SDLC | STLC |
|---|---|
| Software Development Life Cycle | Software Testing Life Cycle |
| Covers the complete software development process | Focuses on the testing process |
| Includes development, testing, deployment, maintenance | Includes testing-specific activities |
| Used by the overall development team | Mainly followed by the testing team |

### Simple Difference

**SDLC → Complete software development process**

**STLC → Complete software testing process**

---

## 4. Relationship Between SDLC and STLC

STLC operates within the overall software development process.

SDLC
→ Requirement
→ Planning
→ Design
→ Development
→ Testing
→ Deployment
→ Maintenance

During the testing activities, the testing team follows STLC:

STLC
→ Requirement Analysis
→ Test Planning
→ Test Case Development
→ Environment Setup
→ Test Execution
→ Test Closure
